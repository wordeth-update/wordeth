FIX 5 — routes/signaling.js — Make restored room deletion grace period smarter
Every restored room currently gets a 10-minute deletion timer immediately on restore. If the host's phone is backgrounded or locked for more than 10 minutes, the room is silently deleted. Use a tiered approach based on room age.
Find inside initRooms():
javascriptrooms.set(roomId, room);
scheduleRoomDeletion(roomId, 'restored-empty');
kept++;
Replace with:
javascriptrooms.set(roomId, room);
const roomAge = now - (room.lastActivity || room.createdAt || now);
const isRecent = roomAge < 30 * 60 * 1000; // less than 30 min old
if (isRecent) {
    scheduleRoomDeletion(roomId, 'restored-empty');
} else {
    // Older rooms get a shorter grace period — clean up faster
    setTimeout(() => {
        const r = rooms.get(roomId);
        if (r && r.participants.size === 0) {
            rooms.delete(roomId);
            deleteRoom(roomId);
            console.log(`[Signaling] Cleaned old restored room ${roomId}`);
        }
    }, 2 * 60 * 1000);
}
