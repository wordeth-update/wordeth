# 🧪 Wordeth Testing - Quick Reference

## 🚀 Start Testing Now

### 1. **Quick Test Run**
```bash
npm test
```

### 2. **Manual API Testing**
```bash
# Start server first
npm start

# In another terminal, run quick tests
node test-manual.js
```

---

## 📋 Available Test Commands

| Command | Description |
|---------|-------------|
| `npm test` | Run all tests with coverage report |
| `npm run test:watch` | Run tests in watch mode (auto-rerun) |
| `npm run test:unit` | Run only unit tests |
| `npm run test:integration` | Run only integration tests |
| `npm run test-config` | Test environment configuration |
| `node test-manual.js` | Interactive API testing tool |
