Audio Bank API Documentation

Rights holders can use this API to submit tracks to the Wordeth Audio Bank. All submissions require admin approval before going live.

Authentication

Include your API key in the X-API-Key header with every request.

X-API-Key: wdth_your_api_key_here

Base URL


                    


                    

                        

                            POST
                            /api/audiobank/tracks
                            Submit a new track
                        

                        

                            
Content-Type: multipart/form-data

                            

                                
FieldTypeRequiredDescription

                                
audiofileYesAudio file (max 15MB)

                                
titlestringYesTrack title

                                
tokenPricenumberYesRental price in tokens (min 1)

                                
artiststringNoArtist name

                                
genrestringNoGenre category

                                
moodstringNoMood tag

                                
bpmnumberNoBeats per minute

                                
durationnumberNoDuration in seconds (default: 30)

                                
rentalDaysnumberNoRental period in days (default: 30)

                                
tagsstringNoComma-separated tags

                                
previewfileNoPreview clip file

                                
coverfileNoCover art image

                            

                            
Example (cURL)

                            
curl -X POST /api/audiobank/tracks \
  -H "X-API-Key: wdth_your_key" \
  -F "audio=@mysong.mp3" \
  -F "title=Summer Vibes" \
  -F "artist=DJ Cool" \
  -F "genre=electronic" \
  -F "mood=energetic" \
  -F "tokenPrice=10" \
  -F "tags=summer,dance,upbeat"

                            
Response

                            
{
  "success": true,
  "track": {
    "id": "...",
    "title": "Summer Vibes",
    "artist": "DJ Cool",
    "status": "pending_review",
    "message": "Track submitted successfully."
  }
}

                        

                    


                    

                        

                            GET
                            /api/audiobank/tracks
                            List your submitted tracks
                        

                        

                            
Query params: status (active/pending), genre, mood, page, limit

                        

                    


                    

                        

                            PUT
                            /api/audiobank/tracks/:id
                            Update track metadata
                        

                        

                            
JSON body with any fields to update: title, artist, genre, mood, bpm, tokenPrice, rentalDays, tags, duration

                        

                    


                    

                        

                            DELETE
                            /api/audiobank/tracks/:id
                            Deactivate a track
